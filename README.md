# 自律日记

自律日记是一款面向 iPhone 的个人记录应用。你可以制定自律周期和训练计划，并按天记录饮食、饮水、训练、睡眠和体重。

## 主要功能

- **概况** · 查看周期进度、当天训练安排、热量、饮水、睡眠和近期体重。
- **记录** · 内置 113 种食物和 18 项运动预设。饮食统计显示蛋白质、碳水和脂肪的摄入量与每日参考值，数值和时间可通过滚轮录入。
- **规划** · 设置周期起止日期，按天编排训练与休息，并校准今天在训练循环中的位置。
- **设置** · 编辑个人档案和目标，管理自定义食物，导出或恢复 JSON 备份。热量、饮水和营养参考值会随档案、最新体重和自律目标更新。

档案和记录保存在本机。你可以在设置页导出备份，并自行选择存放位置。
